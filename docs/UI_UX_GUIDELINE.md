# UI/UX Guideline

## Brand tokens
- Deep Forest: `#102C25`
- Emerald: `#16845B`
- Lime Accent: `#C5F36B`
- Off White: `#F7F8F5`
- Charcoal: `#171C1A`
- Soft Gray: `#E8ECE9`

## Visual principles
1. Premium technology studio, not generic template.
2. Strong typographic hierarchy and generous whitespace.
3. Real product screenshots preferred; clearly labeled illustrative mockups when originals are unavailable.
4. Motion should clarify state and add polish, never obstruct reading or accessibility.
5. Consistent buttons, cards, forms, navigation, badges, and empty states.
6. Responsive layouts designed mobile-first.
7. Provide keyboard focus, accessible labels, sufficient contrast, and reduced-motion support.

## Public home composition
1. Navigation with product/services/insights/contact.
2. Hero with concise value proposition and primary CTA.
3. Featured product showcase with device mockups.
4. Product categories.
5. Services and capabilities.
6. How demo works.
7. Why NEXORA.
8. Case studies/testimonials (only verified).
9. Latest insights.
10. Consultation CTA and footer.

## Product detail composition
- Product identity and availability status.
- Clear problem/value statement.
- Feature highlights.
- Screenshots and demo video.
- Demo CTA with duration/limitations disclosure.
- Pricing or request quote.
- FAQ and related products.

## Demo UX
- Visible remaining time and clear end-session behavior.
- Watermark must not cover critical controls.
- Explain that demo uses sample data and restricted permissions.
- Offer consultation CTA when session ends.

## Admin UX
- Persistent sidebar and clear page title.
- Summary cards only where metrics are real.
- Search, filters, pagination, bulk actions where useful.
- Confirm destructive actions.
- Loading, error, empty, and success states.

## Content Studio UX
- Guided workflow: choose product → goal → format → concept → edit → render → preview → export.
- Show generation status, estimated cost when known, and failure recovery.
- Never show a download action before the asset exists and is verified.
